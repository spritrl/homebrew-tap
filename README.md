# spritrl/homebrew-tap

Homebrew tap for [spritrl](https://github.com/spritrl)'s projects.

```bash
brew tap spritrl/tap
brew install --cask claude-usage
```

| Cask | Description |
| --- | --- |
| [`claude-usage`](Casks/claude-usage.rb) | [Claude Usage](https://github.com/spritrl/claude-usage) — menu bar app showing Claude session and weekly usage in real time |

The `claude-usage` cask is updated automatically by the app's release workflow.
